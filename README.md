# Pharma-Green-Chain-Pharmaceutical-Waste-Financial-Risk-Analytics
About the Project
This project was developed to analyze circular economy and green transition opportunities within the pharmaceutical supply chain. To reduce the environmental impact of pharmaceutical waste and evaluate operational disposal costs, the project simulates source-segregation of packaging waste and a financial risk-oriented reverse logistics analysis.
The dataset consists of 10,000 synthetic English pharmaceutical records generated using Python for analytical purposes.
Tech Stack
Data Generation & Processing: Python, Pandas, NumPy
Database Management & Querying: SQLite, SQL
Data Visualization: Matplotlib, Seaborn, Plotly Express

Analytics & SQL Queries
Using an in-memory SQLite database (:memory:), the project implements the following business analytics workflows:
Packaging Separation Waste Analysis: Compares packaging weights with net drug weights to calculate potential waste reduction volumes by category if packaging separation is implemented.
Financial Risk Distribution: Analyzes the total financial risk values generated by disposal methods—specifically Incineration, Dilution & Sewage, and Landfill—over total inventory value utilizing GROUP BY, SUM, COUNT, ROUND, and ORDER BY.
Visualizations

Financial Risk Value under Disposal Methods (Plotly Interactive Donut Chart)
Key Findings & Business Impact
Separating packaging weight from pharmaceutical waste demonstrates a potential reduction of approximately 75% in total waste weight within the simulated dataset.
Incineration emerges as the disposal method with the highest total financial risk value, accounting for approximately 130 million USD.
The findings highlight that integrating packaging segregation, inventory tracking, and strategic disposal method selection is vital for optimizing both sustainability and financial risk management in the pharmaceutical supply chain.
Note: The dataset utilized in this project was synthetically generated via Python for educational and analytical purposes. The findings do not represent any real company or actual pharmaceutical inventory.
